# PoGoLeiria

PoGoLeiria is a React Native Application build around the data retrieved off the Python Web Application [PoGoLeiria](https://pogoleiria.pt).

This application integrates with various others services such as the Python Bot [Poliswag](https://github.com/rubendgpedrosa/Poliswag).

## Installation

Install packages related to the project by using [Yarn](https://yarnpkg.com/).

```bash
cd PoGoLeiria && yarn install
```

## Usage

Grab a device that will install a version of [Expo Go](https://expo.dev/client).

```bash
npx expo start --tunnel
```

Connect using the QR code and you're set.
